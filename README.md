# JavaScript Calculator 🧮
A modern and interactive calculator built using **HTML, CSS, and JavaScript**. This project features a clean and user-friendly interface designed to perform basic mathematical calculations.

## 🚀 Features
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Decimal number support
- Clear (C) functionality
- Interactive calculator buttons
- Simple and clean user interface

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript

## 📸 Project Preview
The calculator features a modern dark-themed design with orange operator buttons and a simple numeric keypad for a smooth user experience.

## ⚙️ How to Run
1. Clone this repository:

   ```bash
   git clone https://github.com/your-username/javascript-calculator.git
   ```

2. Open the project folder.
3. Open `index.html` in your web browser.

## 🎯 Project Purpose
This project was developed to practice JavaScript fundamentals, understand basic mathematical operations, and improve frontend development skills by building an interactive calculator.
